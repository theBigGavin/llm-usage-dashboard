# llm-usage-dashboard

一个**零依赖、单页面**的本地 LLM 服务用量看板：把本地推理引擎的 token 消耗、吞吐、上下文分布、
健康度与**来源归属**，画成一张适合长期观察的页面。

没有框架、没有构建步骤、没有 CDN —— `index.html` 自己手写 SVG，`aggregate_all.py`（纯标准库）
把引擎日志与请求账本聚合成 `data.json`。

## 它补的是哪些盲点

本地 LLM 服务常见的信息缺口，这个看板逐个补上：

| 盲点 | 做法 |
|---|---|
| 只知道"跑了多少 token"，不知道**谁在用** | 服务包装层按来源（本机 / 局域网 / 隧道）记账；对端地址、UA、队列深度在队列闸门**授予回合那一刻**采集（并发时按到达时刻采会串号） |
| **没跑完的请求完全不可见** | 所有响应（含 4xx/5xx、客户端中途离开）统一在唯一出口记账；健康度面板按天堆叠「正常 / 触顶截断 / 被取消 / 失败」 |
| **单个尖峰压平纵轴** | 吞吐图用对数纵轴（1-2-5 阶梯，且刻度按**像素间距**筛，不由数量级决定），实测把常态带的像素跨度从 17.6% 提到 50% |
| 输入:输出 ≈ 100:1，**画在一根柱子里小的那端就消失了** | 各自成图、各自定标，比值单列一条曲线 —— 这是几何决定的，换调色板救不了 |
| 引擎一换，**口径变了**，读数像"效率崩了" | 在比值曲线上标出切换点：不同引擎的 prompt 口径不同（只算实读 vs 含缓存复用），量级跳变是事实不是 bug |
| 单序列引擎里 **"慢"不是 t/s 低，而是占住那一格太久** | 「峰值与长尾」按**占用时长**列出最慢的几次：卡死与失败请求的 t/s 为 0，永远进不了"最快榜"，只有这里看得见 |

## 架构

```
引擎日志 / 指标 ─┐
                 ├─► aggregate_all.py ──► data.json ──► index.html
按来源请求账本 ──┘     (纯标准库)          (原子写回)    (手写 SVG，零依赖)
```

- **明细账本**是 append-only 的 JSONL，服务包装层每完成一次请求追加一行。
- **日汇总**落在 SQLite（`usage.db`），与明细清理解耦：将来明细只保留 N 天，历史日汇总不会跟着消失。
  用数据库而不是 JSON 文件的原因是原子性 —— "读全量 → 改 → 覆写"的 JSON 一旦在进程被杀时中断，就会留下半截文件。
- 页面每 2 分钟重取 `data.json`；聚合器用临时文件 + `os.replace` 原子写回。

## 快速开始

```bash
cp data.sample.json data.json       # 先用脱敏样片看效果
python3 -m http.server 18081        # 打开 http://127.0.0.1:18081/
# 有真实数据后：
python3 aggregate_all.py            # 重新聚合出 data.json
```

`data.sample.json` 由 `tools/make_sample.py` 生成，采用**白名单**重建：只挑选页面确实需要的字段，
而不是"复制一份再删敏感项"—— 后者一旦漏掉某个嵌套字段（对端、UA、路径），敏感内容就跟着上仓库了。
对端地址映射到 RFC 5737 文档保留地址（`192.0.2.x` / `198.51.100.x` / `203.0.113.x`），计数统一缩放。
真实的 `data.json`、账本、日志、数据库都在 `.gitignore` 中。

## 接入你自己的引擎

聚合分两半：`aggregate.py` 解析 llama.cpp 的 `slot print_timing` 日志（历史），
`aggregate_all.py` 合并新引擎的请求账本。接一个新引擎只需让它产出同样形状的账本行：

```json
{"ts": "2026-10-15T17:16:02", "source": "local", "peer": "127.0.0.1", "ua": "node",
 "wait_ms": 0, "hold_ms": 4800, "prompt_tokens": 35061, "generated": 239, "reused": 34000,
 "drafts_accepted": 14, "drafts_offered": 25, "prompt_ms": 1750.7, "decode_ms": 4053.8,
 "finish": "stop", "http_status": 200}
```

采集/聚合的路径常量在 `aggregate_all.py` 顶部，按你的目录结构改即可。

## 说明

代码注释里逐条记录了踩过的坑与原因（缓存计数器语义、0ms 幽灵行、掉速异常值、
